# Phase 9 — PDF Faculty Feedback Report

## Context

The IRB protocol promises each participating instructor a "Faculty Feedback Report" — a concrete, actionable summary translating the AI analysis into something useful for the professor. This phase generates that PDF.

## Install

```bash
uv add reportlab plotly kaleido
```

- `reportlab` — Python PDF generation
- `kaleido` — renders plotly charts to static images for embedding in the PDF

## File

**`report/pdf_report.py`**

## Function Signature

```python
def generate_faculty_report(
    professor_name: str,

    survey_data: dict,       # optional — parsed survey summary

```

Each `lecture_results` dict contains:
```python
{
    "lecture_id": "lecture_001",
    "results_csv_path": "output/dr_smith/lecture_001/results_multimodal.csv",
    "dashboard_html_path": "output/dr_smith/lecture_001/dashboard.html"
}
```

## PDF Structure

### Page 1: Cover Page
- Title: "Faculty Feedback Report"
- Professor name, course, semester
- Date generated
- USF logo (if available) or text header
- Disclaimer: "Generated by the Bridging the Feedback Gap AI Tool. For pedagogical development only."

### Page 2: Executive Summary
- 1 paragraph overview of the analysis
- Number of lectures analyzed
- High-level behavioral profile: % time lecturing vs. active learning across all 3 lectures
- Key finding: most and least frequent codes

### Page 3–5: Per-Lecture Behavioral Timeline (1 page each)
- Lecture ID and date
- Plotly timeline chart rendered as static image
- Code frequency table for that lecture:
  - Code | Windows Present | % of Total Windows
- Brief AI-generated narrative describing the lecture pattern (e.g. "This lecture was predominantly lecture-based with two transitions to Q&A in the middle third")

### Page 6: Validation Summary
- κ scores table: AI vs Human for each code
- Color indicators for reliability levels
- Brief note on inter-rater reliability (Sofia vs Dr. Kaw)

### Page 7: Student Engagement Correlation (if survey data provided)
- Aggregated survey scores
- Correlation between active-learning ratio and engagement
- AI-generated feedback: "Lectures with higher PQ/AnQ frequency correlated with higher student engagement scores"

### Page 8: Recommendations
- AI-generated recommendations based on COPUS patterns
- E.g. "Consider incorporating more questioning (PQ) in the first 20 minutes of lecture, where the data shows continuous Lec codes"
- Frame as suggestions, not evaluations (per COPUS philosophy)

## Chart Rendering

Use `plotly` to generate charts, then `kaleido` to export as PNG:

```python
import plotly.graph_objects as go
fig.write_image("chart.png", width=800, height=400, engine="kaleido")
```

Then embed PNG in the PDF via `reportlab`.

## AI-Generated Narrative

For the per-lecture narrative and recommendations, use Gemini:
- Send the `results.csv` for that lecture + survey summary (if available)
- Prompt: "You are a pedagogical consultant. Based on this COPUS behavioral data, write a 3-4 sentence summary of this lecture's teaching style and 2-3 specific, constructive recommendations for the instructor."
- Keep it brief and actionable
